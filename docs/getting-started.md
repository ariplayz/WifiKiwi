# Getting started

This is a placeholder until the first hardware revision is fabricated and
the firmware can boot to the home screen.

## What you'll have when this guide is complete

1. A flashed and assembled WifiKiwi unit with a working touchscreen.
2. Two antennas (low-band and high-band).
3. A Faraday cage and at least one AP/device you own to test against.

## Order of operations (planned)

1. Read [`legal-and-safe-use.md`](legal-and-safe-use.md). **Do not skip this.**
2. Order the PCB from JLCPCB using files in `hardware/gerbers/`.
3. Order the BOM from LCSC + AliExpress per `hardware/bom/bom.csv`.
4. Assemble per [`hardware-assembly.md`](hardware-assembly.md) (TBD).
5. Build & flash the firmware per [`firmware-build.md`](firmware-build.md) (TBD).
6. Read the [`ui-guide.md`](ui-guide.md) (TBD).

Until those guides are written, follow the project plan in `docs/plan.md`
(when published) and the README at the repo root.
