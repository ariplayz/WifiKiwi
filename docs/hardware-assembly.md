# Hardware assembly

🚧 **TBD** — this guide will be written once the first PCB revision is
fabricated and successfully bring-up has been done.

## Outline (planned)

1. Tools required (soldering iron, hot-air, flux, microscope optional).
2. PCB inspection checklist on receipt from JLCPCB.
3. Bottom-side SMD assembly (passives, switches, regulators) — JLC PCBA
   handles most of this if ordered with assembly.
4. Top-side hand-placed: ESP32-C5-WROOM-1U, CC1101 module, ADF4351 module,
   PE4259 switches, PE43711 attenuators, SPF5189Z LNAs, U.FL test pads.
5. Through-hole: SMA connectors, headers, joystick, tactile buttons,
   18650 holder.
6. Internal USB-A receptacle for RTL-SDR.
7. Touchscreen ribbon connection.
8. First power-up test sequence (current draw, rail voltages, no smoke
   check).
